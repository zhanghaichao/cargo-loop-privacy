CARGO LOOP

隐私政策

Cargo Loop · Jocelyn · 更新日期：2026-09-15

关于本政策

本政策适用于由 Jocelyn 提供的 Cargo Loop 安卓游戏（包名 com.jocelyn.cargoloop）。当前游戏支持离线游玩，无需注册或登录账号。

本机处理的数据

游戏在本机保存当前选中关卡、已完成关卡和教学进度，以便继续游玩；同时保存音乐与音效开关、音量、震动偏好和语言选择。选择跟随系统语言时，游戏仅在本机读取系统语言。这些信息不会由游戏发送给我们或第三方。

收集与共享

当前游戏不向设备外传输个人数据，不出售数据，也不向第三方共享游戏数据。游戏未接入广告、统计、账号或应用内购买服务，不申请位置、通讯录、相机、麦克风或照片权限。当前安卓构建没有联网权限。

震动

游戏使用安卓震动权限提供操作反馈，可在设置中关闭。此功能不收集您的个人信息。

存储、保留与删除

关卡进度和设置存放在应用私有存储中，直到您在安卓设置中清除应用存储或卸载游戏。当前安卓构建已关闭应用备份。我们不持有进度的服务器副本，因此无法在删除后恢复。清除存储会同时移除您的关卡进度和设置。

主动联系支持

如果您主动向 seansheaton@gmail.com 发送邮件，我们将收到您的邮箱地址和邮件中提供的信息，用于回复问题、处理请求，并仅在处理所需期间或适用法律要求的期限内保留。邮件由您和我们使用的邮件服务商处理。请勿发送密码或其他敏感信息。您可联系同一邮箱申请删除支持邮件中的信息。

儿童相关信息

当前游戏对任何年龄的玩家均不提供账号注册或个人信息收集功能。如果您认为儿童通过支持邮件提供了个人信息，可联系我们处理，并在适当情况下删除。

政策变更

如后续版本新增功能并改变数据处理方式，我们会更新本政策及相关商店声明。页面日期表示最近一次政策修订时间。

联系方式

开发者：Jocelyn 隐私与支持邮箱：seansheaton@gmail.com

隐私政策网站

设置中的隐私入口会在外部浏览器打开此网站。网站由 GitHub Pages 托管。GitHub 可能依据其隐私声明处理 IP 地址、浏览器信息等连接数据，以提供网站服务与安全保护。我们未在此网站加入统计脚本或广告追踪。打开链接不会将您的游戏进度或设置发送到网站。
